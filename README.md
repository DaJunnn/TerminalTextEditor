# Terminal Text Editor

## Project Description
A simple terminal-based text editor developed in Java.

## Features
1. Input / Edit Text
2. Search Keyword and Count
3. Replace Text
4. Auto Wrap Preview
5. Text Statistics
6. Show Current Text

## Technologies
- Java
- NetBeans
- Object-Oriented Programming
- StringBuilder
- indexOf()
- replace()
