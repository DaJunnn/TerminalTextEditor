# Terminal Text Editor

## 特色
我們這組做的是一款基於 Java 終端機的輕量文字處理工具。雖然它沒有複雜的圖形介面，但它的核心就是「簡單、流暢、效率高」。我們在專案中運用了物件導向、字串動態處理和搜尋演算法，做出了四大核心功能：「關鍵字搜尋」、「計算字詞出現次數」、「文字取代」，以及超實用的「自動換行預覽」。不管是要找重點還是排版，用這個工具都非常方便。

## 功能介紹
1. Input / Edit Text
2. Search Keyword and Count
3. Replace Text
4. Auto Wrap Preview
5. Text Statistics
6. Show Current Text

## 使用技術
- Java
- NetBeans
- Object-Oriented Programming
- StringBuilder特色
- indexOf()
- replace()
